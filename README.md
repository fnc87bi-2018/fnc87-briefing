# FNC87 | Me Conte sua História

Repositório independente do formulário de briefing da FNC87 | Estúdio Digital.

## Publicação

Este projeto é uma página estática. Para publicar no Cloudflare Pages:

1. Crie um repositório GitHub chamado `fnc87-briefing`.
2. Envie `index.html` para a raiz do repositório.
3. No Cloudflare Pages, crie um projeto conectado a esse repositório.
4. Configure o framework como `None` (ou sem framework), Build command vazio e diretório de saída `/`.

O formulário mantém a integração existente com o Google Apps Script. Não altere o endpoint nem os nomes dos campos sem atualizar também o Apps Script.
